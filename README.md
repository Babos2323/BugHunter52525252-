# BugHunter
Система управления жизненным циклом программных дефектов.

## Технологии
PHP 8+, SQLite, PDO, HTML/CSS.

## Требования
- PHP 8.0+
- Расширения `pdo_sqlite`, `sqlite3`

## Установка
1. Клонируйте репозиторий.
2. Создайте базу данных: `sqlite3 bughunter.db < schema.sql`
3. Запустите сервер: `php -S 127.0.0.1:8000`
4. Откройте `http://127.0.0.1:8000` в браузере.

## Тестовые аккаунты
- Логин: `tester` | Пароль: `12345` (Тестировщик)
- Логин: `admin` | Пароль: `12345` (Администратор)
- Логин: `developer` | Пароль: `12345` (Разработчик)

## Функционал
- Управление статусами ошибок (жизненный цикл).
- Разграничение прав доступа (RBAC).
- История изменений и комментарии.
- Поиск, фильтрация, пагинация.
- Панель аналитики (Dashboard).
